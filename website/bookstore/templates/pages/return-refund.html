Quick Refund

Check hone ke baad 5-7 working days mein paisa wapas.

1. Return Ki Shartein (Eligibility)

Return tabhi liya jayega jab product damaged ho, galat item deliver hua ho, ya usmein koi manufacturing defect ho. Item ka unused hona aur original packing mein hona anivarya hai.

2. Non-Returnable Items

Niche diye gaye cases mein return ya exchange nahi ho payega:

  • Digital content ya E-books.
  • Items jo 7 dino ki limit ke baad report kiye gaye hon.
  • Used ya damaged products (jo user ki wajah se huye hon).

3. Refund Kaise Milega?

Ek baar jab humein aapka return mil jayega aur hum use inspect kar lenge, toh hum aapko email ke zariye soochit karenge. Approved refund automatically aapke original payment method (Bank/UPI/Card) mein bhej diya jayega.

Note: Shipping charges non-refundable ho sakte hain.

4. Cancellation Policy

Aap apna order ship hone se pehle kabhi bhi cancel kar sakte hain. Order ship hone ke baad use cancel nahi kiya ja sakta, uske liye aapko return process hi follow karna hoga.
